# 穀倉門 — 首日試玩 v0.1

第一人稱點選網頁原型，約 10–15 分鐘。2126 年 9 月 16 日，從寢室起床、用餐、接班，查核貨單外的一箱耗材，最後交班與回顧。

## 本機執行

在本資料夾執行 `python3 -m http.server 4173 --directory dist`，瀏覽器開啟 http://localhost:4173 。需要 HTTP 伺服器，請勿直接以 file:// 開啟 index.html，因為程式使用 ES modules。沒有依賴安裝或建置步驟。

測試：Node.js 18+ 執行 `npm test`，14 項狀態機測試。瀏覽器實測以 WebKit 為主，未聲稱所有瀏覽器及裝置均通過。

## 操作

滑鼠／觸控點選地點和場景標記，J 事件簿、R 名冊、Esc 關閉。對話及閱讀不推進時間；工作按鈕標示耗時。事件簿可搜尋、查看來源附件、追加補註、匯出 JSON。流程和按鈕支援鍵盤；焦點保留、放大字、聲音字幕、減少動態可於設定調整。

完整查核、退回、留置交接、委派及未核驗放行各有結果。沒有唯一隱藏正解；未核驗放行會留下程序缺口，不會任意製造感染。月度草案可儲存，本日不生效。

## 範圍與資料

四個固定概念場景，不是自由移動 3D。音效為 Web Audio 合成底噪與按鍵音，無配音。全年天候、其他庇護所、完整檢疫、人物養成與跨月排班尚未實作。三難度目前影響初始儲備、醫療回覆時間及參考門檻；單日結果不是全年勝負。

存檔與設定僅保存在同一瀏覽器／網址的 localStorage，可能因清除瀏覽資料或無痕模式失去；可匯出紀錄保留。不同網址的存檔彼此獨立。匯出 JSON 是試玩報告，本版不支援匯入。
