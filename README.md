# 穀倉門 — 三天試玩 v0.2

這次可以連續玩 2126 年 9 月 16、17、18 日。約 20–30 分鐘，採第一人稱點選場景，尚不是自由走動的 3D 遊戲。

## 怎麼開始

跟著畫面上的提醒：拿裝備 → 吃早餐 → 聽上一班交代 → 接班 → 處理今天的事 → 交代給下一班 → 下班。

交班有兩步。先說清楚今天做了什麼、還有什麼沒做完，同事答應接手後才能下班。下班會略過平靜時段到下午四點，然後可以休息到隔天。

- 第一天：收貨，多了一箱沒登記的東西。
- 第二天：追蹤昨天的箱子，安排修指紋機，也要有人顧門。
- 第三天：可能下大雨，送貨地點又有變動，需要問清楚。

昨天的安排會影響今天。暫存箱子會有後續，延後修機器會讓工程師隔天更忙。三天都有不同選擇。

J 看事件簿，R 看誰在做什麼，Esc 關閉視窗。看說明不花遊戲時間，做事和等待才會。事件簿可找人員、日期和時間、看資料來源、補充紀錄、下載這次的結果。

## 儲存與限制

進度只存在同一個瀏覽器／網址，不會上傳。舊版第一天的進度可接著玩；若想重看新順序，可選「開始這一天」開新進度。不同網址的進度各自獨立。下載的 JSON 是紀錄，本版不能讀回。

人物改成日常工作姿態，但仍是固定圖片，還沒有動態人物或配音。聲音先用簡單通風底噪和按鍵音，可關閉。尚無全年天候、完整健康檢查及跨月排班；排班只先記草稿。

## 在自己電腦執行

在此資料夾執行 `python3 -m http.server 4173 --directory dist`，再開啟 http://localhost:4173 。請勿直接雙擊 index.html，因為程式需要網頁伺服器。沒有額外套件要安裝。

Node.js 18+ 執行 `npm test`：21 項規則測試，包括 30 種跨日選擇組合。瀏覽器已玩完 held → repaired → verified 三天路線、測試存檔恢復與手機說明畫面；另走查委派，確認修好後工程師／維修紀錄及第三天對講機／後勤說明會更新。未宣稱所有瀏覽器皆完整通過。

美術由內建 imagegen 生成／編輯，詳見 UPDATE-v02.md。場景以 CSS 顯示圖集各區，人物位置不隨故事變動。
